# Assel E-Commerce

A responsive e-commerce storefront for fashion and accessories, built as a frontend project. Product data comes from a third-party REST API.

**Live demo:** https://assel-ecommerce.vercel.app/

## Features

- Browse products by category: women's clothing, earrings, watches, heels and sneakers
- Filter products
- Product detail pages
- Shopping cart with state managed in Redux Toolkit
- Responsive layout for mobile and desktop

## Tech Stack

React, Next.js, TypeScript, Redux Toolkit, Tailwind CSS

## Getting Started

```bash
git clone https://github.com/bkar-ali/assel-ecommerce.git
cd assel-ecommerce
npm install
npm run dev
```

Open http://localhost:3000.
